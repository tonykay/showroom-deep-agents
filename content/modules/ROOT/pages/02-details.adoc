= Environment Setup

Before you can build agentic systems with Deep Agents, you need to prepare your development environment. This guide will walk you through installing Python, the `uv` package manager, and the Deep Agents library.

== Install Python 3.13+

Deep Agents requires Python 3.13 or later. Verify your Python version:

[source,role="execute"]
----
python3 --version
----

If you need to install or upgrade Python, consider using https://github.com/pyenv/pyenv[pyenv] (on macOS/Linux) or https://brew.sh[Homebrew] (macOS: `brew install python@3.13`).

== Install uv

https://github.com/astral-sh/uv[uv] is a fast Python package manager that simplifies dependency management. Install it with:

[source,role="execute"]
----
curl -LsSf https://astral.sh/uv/install.sh | sh
----

Verify the installation:

[source,role="execute"]
----
uv --version
----

== Create your workshop project

Initialize a new Python project and install Deep Agents:

[source,role="execute"]
----
uv init deep-agents-workshop
cd deep-agents-workshop
uv add deepagents
----

This creates a project directory with a `pyproject.toml` file and installs the Deep Agents library along with its dependencies.

== Set your API key

Deep Agents uses Claude as its reasoning engine. You'll need an Anthropic API key to run the examples in this workshop.

[source,role="execute"]
----
export ANTHROPIC_API_KEY="your-key-here"
----

You can obtain an API key from https://console.anthropic.com[console.anthropic.com]. Navigate to "API Keys" in your account settings and create a new key.

NOTE: You'll need this API key set for all modules in this workshop. Consider adding it to your shell profile (`~/.bashrc`, `~/.zshrc`, etc.) to persist it across sessions.

== Validate your setup

Create and run a simple validation script to confirm everything is working:

[source,role="execute"]
----
cat > validate_setup.py << 'EOF'
from deepagents import create_deep_agent

agent = create_deep_agent()
print("Deep Agents installed successfully!")
print(f"Agent type: {type(agent).__name__}")
EOF
uv run python validate_setup.py
----

Expected output:

[source,python]
----
Deep Agents installed successfully!
Agent type: CompiledStateGraph
----

If you see this output, your environment is ready for the workshop!

== Install the Deep Agents CLI

The Deep Agents CLI provides helpful commands for scaffolding projects and running agents. Install it with:

[source,role="execute"]
----
curl -LsSf https://raw.githubusercontent.com/langchain-ai/deepagents/main/libs/cli/scripts/install.sh | bash
----

Verify the installation:

[source,role="execute"]
----
deepagents --help
----

The CLI is optional but can accelerate your development workflow.

== Optional: Local Showroom experience

This launches a browser-based interface that mirrors the online Showroom experience.

== Troubleshooting

=== Python version too old

If `python3 --version` shows a version older than 3.13, you'll need to upgrade. Use pyenv or your system package manager:

[source,python]
----
# Using pyenv
pyenv install 3.13
pyenv global 3.13

# Using Homebrew (macOS)
brew install python@3.13
----

=== API key not set

If you see authentication errors when running examples, ensure your `ANTHROPIC_API_KEY` environment variable is set:

[source,role="execute"]
----
echo $ANTHROPIC_API_KEY
----

If this prints an empty line, re-export your API key.

=== uv not on PATH

After installing `uv`, you may need to restart your terminal or manually add it to your PATH. The installer typically adds it to `~/.cargo/bin`. Check your shell profile and add:

[source,python]
----
export PATH="$HOME/.cargo/bin:$PATH"
----

Then restart your terminal or run `source ~/.bashrc` (or `~/.zshrc`).
