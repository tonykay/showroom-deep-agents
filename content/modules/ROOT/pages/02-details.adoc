= Environment Setup

Before you can build agentic systems with Deep Agents, you need to prepare your development environment. This guide will walk you through installing Python, the `uv` package manager, and the Deep Agents library.

== Check your Python version

Deep Agents requires Python 3.13 or later. Check what you have:

[source,role="execute"]
----
python3 --version
----

Don't worry if your system Python is older -- in the next section you'll install `uv`, which can download and manage Python 3.13 for your project automatically without touching your system installation.

== Install uv

https://github.com/astral-sh/uv[uv] is a fast Python package and project manager from Astral. It handles dependency management, virtual environments, and -- crucially for this workshop -- **Python version management** per project, so you never need to change your system Python. Install it with:

[source,role="execute"]
----
curl -LsSf https://astral.sh/uv/install.sh | sh
----

Verify the installation:

[source,role="execute"]
----
uv --version
----

You should see version **0.6.x or later**. If you have an older version, re-run the install script above to upgrade.

== Create your workshop project

Initialize a new project pinned to Python 3.13. Even if your system Python is an older version, `uv` will automatically download and manage Python 3.13 for this project:

[source,role="execute"]
----
uv init --python 3.13 deep-agents-workshop
cd deep-agents-workshop
uv add deepagents
----

This creates an isolated project directory with its own `pyproject.toml`, `.python-version` file (pinned to 3.13), and virtual environment. Your system Python is untouched -- `uv` downloads and caches the correct Python version automatically.

You can verify which Python the project is using:

[source,role="execute"]
----
uv run python --version
----

This should show `Python 3.13.x` regardless of what `python3 --version` reports system-wide.

TIP: This per-project Python management is one of the key reasons we use `uv` throughout this workshop. Each project gets exactly the Python version it needs, and you can have multiple projects using different versions side by side.

== Set your API key

Deep Agents uses Claude as its reasoning engine. You'll need an Anthropic API key to run the examples in this workshop.

[source,role="execute"]
----
export ANTHROPIC_API_KEY="your-key-here"
----

You can obtain an API key from https://console.anthropic.com[console.anthropic.com]. Navigate to "API Keys" in your account settings and create a new key.

NOTE: You'll need this API key set for all modules in this workshop. Consider adding it to your shell profile (`~/.bashrc`, `~/.zshrc`, etc.) to persist it across sessions.

== Validate your setup

Create and run a simple validation script to confirm everything is working:

[source,role="execute"]
----
cat > validate_setup.py << 'EOF'
from deepagents import create_deep_agent

agent = create_deep_agent()
print("Deep Agents installed successfully!")
print(f"Agent type: {type(agent).__name__}")
EOF
uv run python validate_setup.py
----

Expected output:

[source,python]
----
Deep Agents installed successfully!
Agent type: CompiledStateGraph
----

If you see this output, your environment is ready for the workshop!

== Install the Deep Agents CLI

The Deep Agents CLI provides helpful commands for scaffolding projects and running agents. Install it with:

[source,role="execute"]
----
curl -LsSf https://raw.githubusercontent.com/langchain-ai/deepagents/main/libs/cli/scripts/install.sh | bash
----

Verify the installation:

[source,role="execute"]
----
deepagents --help
----

The CLI is optional but can accelerate your development workflow.

== Troubleshooting

=== Python version too old

If `uv run python --version` inside your project still shows an older version, ensure you created the project with the `--python 3.13` flag. You can fix an existing project by running:

[source,role="execute"]
----
uv python pin 3.13
uv sync
----

This tells `uv` to download Python 3.13 and recreate the virtual environment. Your system Python remains unchanged.

=== API key not set

If you see authentication errors when running examples, ensure your `ANTHROPIC_API_KEY` environment variable is set:

[source,role="execute"]
----
echo $ANTHROPIC_API_KEY
----

If this prints an empty line, re-export your API key.

=== uv not on PATH

After installing `uv`, you may need to restart your terminal or manually add it to your PATH. The installer typically adds it to `~/.cargo/bin`. Check your shell profile and add:

[source,python]
----
export PATH="$HOME/.cargo/bin:$PATH"
----

Then restart your terminal or run `source ~/.bashrc` (or `~/.zshrc`).
