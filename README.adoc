= Deep Agents: From First Agent to Production Multi-Agent Systems

A zero-to-hero workshop on https://github.com/langchain-ai/deepagents[LangChain Deep Agents], covering the Python SDK, CLI, and production deployment patterns. Built with https://antora.org[Antora] on the https://github.com/rhpds/showroom_template_nookbag[Showroom template] for Red Hat Demo Platform.

== What You'll Learn

* Build agents with `create_deep_agent()` — system prompts, planning, filesystem tools
* Define subagents for context isolation and model routing
* Create skills (SKILL.md) for progressive-disclosure capabilities
* Use AGENTS.md for persistent memory and project context
* Work with the Deep Agents CLI — interactive TUI and headless scripting
* Deploy agents with containers and Kubernetes/OpenShift

== Workshop Structure

The workshop progresses through foundations, multi-agent systems, and a capstone, with bonus modules for deeper exploration:

* **Foundations** — first agent, system prompts, filesystem backends, custom tools
* **Multi-Agent Systems** — subagents, YAML loader pattern, skills, memory
* **CLI & Capstone** — Deep Agents CLI, AIOps team capstone project
* **Bonus Modules** — LangFuse tracing, containers, OpenShift, JupyterLab, Claude Code, MCP, security, CLI skills development, project-aware agents
